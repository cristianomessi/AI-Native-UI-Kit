## Installation

```bash
npx shadcn@latest add https://ai-native-ui.com/r/response-actions.json
```

## Usage

```tsx
import { ResponseActions } from "@/components/ui/response-actions";

<ResponseActions
  onAction={(id, prompt) => refine(id, prompt)}
  onFeedback={(kind) => track(kind)}
/>;
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `actions` | `ResponseAction[]` | Menu items (`id`, `label`, `icon`, `submenu`). |
| `onAction` | `(id: string, prompt?: string) => void` | Fires on a menu item or custom prompt. |
| `onFeedback` | `(kind: "copy" \| "up" \| "down" \| "regenerate") => void` | Toolbar feedback. |
